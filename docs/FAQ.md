# 常见问题

## 应该使用哪个账号登录？

使用飞牛音乐中的账号，不是 fnOS 系统账号。先在音桥“账号绑定”页面完成绑定，并确认
该账号拥有需要访问的曲库权限。

## 客户端提示 401 或密码错误怎么办？

1. 在飞牛音乐登录页确认账号密码正确；
2. 检查账号是否被禁用以及是否拥有曲库权限；
3. 在音桥中删除并重新绑定该账号；
4. 删除客户端中的旧连接后重新添加。

如果在音桥绑定账号时就失败，进入“系统设置 -> fnOS 与飞牛音乐”，先点击重新检测。
fnOS 修改过 Web 管理端口时，在“本机 fnOS 网关”填写实际地址，例如
`http://192.168.1.11:14100` 或 `https://192.168.1.11:14101`，保存后再绑定。这里配置的是
fnOS 管理入口，不是播放器的 `14040` 端口。

## “创建音乐账号”打开了错误端口怎么办？

`1.0.7` 起，音桥会从可用的 fnOS Web 网关生成飞牛音乐账号管理地址。系统设置中可以
查看当前识别结果；如果自动结果不符合实际，在“浏览器访问地址”填写可以从当前浏览器
访问的 fnOS 根地址。地址只填写协议、主机和端口，不要带 `/music` 路径。

## 找不到歌曲或曲库为空怎么办？

确认官方飞牛音乐中能看到歌曲，并检查当前账号的共享曲库权限。随后打开音桥“服务概览”，
确认 Yinqiao API 已连接且对应协议已开启。

## 找不到 NAS 局域网 IP 怎么办？

在 fnOS 系统设置的网络信息中查看局域网 IPv4，也可以在音桥“系统设置”中填写固定 IP
或主机名。该字段不要包含协议、端口或路径。

## 可以修改播放器端口吗？

可以。音桥“系统设置”允许修改播放器端口，并单独开启或关闭每种协议。桌面管理入口
仍使用 `14040`；修改后需要同步更新客户端地址。

## 可以从外网连接吗？

可以自行配置 VPN 或 HTTPS 反向代理。音桥不会自动进行内网穿透，也不建议把 HTTP
端口直接映射到公网。

## Jellyfin 客户端为什么没有视频功能？

音桥提供的是 Jellyfin 音乐兼容能力，不是完整 Jellyfin 影视服务器。视频、直播、插件、
SyncPlay 和服务器管理不在支持范围内。

## 升级或卸载会删除音乐吗？

不会。音桥不会保存或删除飞牛音乐曲库。覆盖升级会保留音桥设置；卸载时可以选择保留
或删除音桥自己的账号凭据、设置和日志。
