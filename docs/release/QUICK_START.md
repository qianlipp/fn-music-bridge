# 5 分钟快速上手

1. 在飞牛音乐中创建一个播放器专用账号并授予需要的曲库权限。
2. 安装 `yinqiao-1.0.5.fpk`，从飞牛桌面点击“音桥”。
3. 打开“账号绑定”，输入刚创建的飞牛音乐账号密码，点击“验证并绑定”。
4. 回到“服务概览”，复制类似 `http://192.168.x.x:14040` 的局域网地址。
5. 在播放器中选择协议，填写地址、同一账号和密码：

| 客户端类型 | 服务器填写 | 额外路径 |
| --- | --- | --- |
| Subsonic/Navidrome | `http://NAS_IP:14040` | 不要手填 `/rest` |
| Audio Station | `http://NAS_IP:14040` | 客户端自动发现 `/webapi` |
| Jellyfin | `http://NAS_IP:14040` | 可选反代基础路径 `/Audio` |
| Ampache | `http://NAS_IP:14040` | 客户端自动使用 API 入口 |

连接失败时先确认手机和 NAS 在同一局域网，再打开管理页查看 Yinqiao API 是否“已连接”。
不要把 18090 或 14040 直接映射到互联网。
