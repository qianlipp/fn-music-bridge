# 安装、升级与卸载教程

## 安装前

- fnOS 不低于 `1.2.0300`，当前包为 x86_64。
- 从应用中心安装未修改的官方飞牛音乐并确认可正常播放。
- 如果曾安装把 Yinqiao API 注入官方音乐包的早期实验包，先恢复应用中心官方版本；不要让
  两套服务同时占用 18090/14040。
- 记录当前曲库和账号配置，重要数据先备份。

## 安装

1. 在应用中心选择手动安装，上传 `yinqiao-1.0.5.fpk`。
2. 阅读并确认第三方应用和局域网端口提示。
3. 安装完成后启动应用并点击“打开”。
4. “服务概览”应显示 Yinqiao API 已连接和协议已开启。
5. 在“账号绑定”添加一个或多个飞牛音乐账号。

[图片占位：应用中心手动安装和安装前须知，完整显示第三方与端口提示]

## 设置

“系统设置”可修改播放器端口、指定固定局域网 IP/主机名，并分别开关四种协议。
管理页始终保留在 14040。修改协议端口后，已配置客户端需要同步修改地址。

## 升级

同 appname 的新 FPK 可直接覆盖升级。升级前保留当前安装包和设置截图；升级后检查：

```text
Yinqiao API 已连接 -> 账号仍在 -> 端口和协议开关未变化 -> 客户端可登录 -> 音频可播放
```

如官方飞牛音乐也升级，先单独确认官方应用正常，再测试协议桥，便于区分问题来源。

## 日志

```text
/var/apps/yinqiao/var/log/yinqiao-api.log
/var/apps/yinqiao/var/log/yinqiao-service.log
```

用 `tail -F` 查看，不要直接删除正在写入的日志。单个日志超过 10 MB 后会在下次启动
保留一份 `.1`。对外发送前必须脱敏。

## 卸载

卸载不会停止、卸载或修改官方飞牛音乐。向导提供两个选择：

- 保留本应用的加密凭据、设置和日志，方便稍后重装；
- 删除本应用全部私有数据。

删除本应用数据不会删除飞牛音乐账号、曲库或音乐文件。
