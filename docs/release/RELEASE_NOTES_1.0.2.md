# 音桥 1.0.2

1.0.2 对 Jellyfin 10.10.7 音乐客户端接口做了一次系统性审计。候选二进制连接真实
飞牛音乐曲库完成 81 项通过、0 项失败、5 项明确不支持；这不等同于正式 FPK 已经通过
公网域名复测，安装后仍需运行随包的黑盒验收脚本。

## 新增

- 管理页“关于与安全”，直接说明第三方属性、权限、端口、数据和兼容边界。
- 随包隐私、安全、免责声明和第三方名称/标识说明。
- 安装前局域网端口提示以及更完整的卸载数据选项。
- 社区首发、安装、快速上手、FAQ、商店、审核和宣传物料。

## 安全改进

- 包名和全部运行标识统一为 `yinqiao`，显示名改为“音桥”。
- 使用独立 `yinqiao:yinqiao` 普通应用账号，不再申请 root 运行权限。
- 跨站网页不能调用账号绑定、账号删除或设置修改接口。
- 日志达到 10 MB 后于下次启动轮转一份，避免长期无限增长。
- 构建验证覆盖 FPK 来源、官方依赖、权限、向导、随包文档和 app.tgz 校验和。

## 兼容性

- 固定路由段与 `/Audio`、`/emby`、`/jellyfin` 命名空间不区分大小写。
- 歌曲、专辑、歌手、流派和歌单保持真实总数，并支持跨上游页的 `StartIndex/Limit`。
- `/Items/Counts`、`/Items/Root`、`/Items/Suggestions`、父级子项和搜索提示返回真实数据。
- stream、universal、Download、File、封面和歌词复用原媒体，支持 HTTP Range。
- 用户数据、收藏、已播放、播放事件、会话能力、注销和扫描任务详情可用。
- 歌单支持读、建、改名、加歌、移歌和删除；不支持协作用户和曲目重排。
- Similar、Instant Mix、歌词写入和非音乐能力返回明确错误，不再返回虚假空成功。
- Jellyfin 日志包含脱敏请求参数、响应状态、响应字节数和耗时。
- 保留 Yinqiao API、OpenSubsonic、Audio Station、Jellyfin Audio 和 Ampache。
- 保留多账号、端口自定义和每种协议独立开关。
- FPK appname 改为 `yinqiao`，作为全新独立应用安装，不继承旧测试包数据。

## 已知边界

- 需要官方飞牛音乐正常运行。
- 当前 x86_64；未提供 ARM 构建。
- 默认服务是可信局域网明文 HTTP，不应裸露到互联网。
- 官方音乐接口变化后，部分映射可能需要更新。
- 本版本只兼容 Jellyfin 音乐客户端所需子集，不是完整 Jellyfin 影视服务器。

详细接口状态见 `docs/JELLYFIN_10_10_7_MATRIX.md`，自动验收方法见
`autotest/README.md`。
