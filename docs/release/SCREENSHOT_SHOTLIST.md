# 截图与图片制作清单

所有截图使用测试账号和无隐私曲库。用户名、内网 IP 最后一段、域名、歌曲私人标签和
日志内容必须打码。不要出现 Token、密码、密钥文件或用户目录。

| 编号 | 尺寸建议 | 内容与构图 | 说明文字 |
| --- | --- | --- | --- |
| 01 | 1920x1080 | 飞牛桌面 + 应用窗口服务概览 | 第三方独立应用，一处连接多种播放器 |
| 02 | 1600x1000 | 服务概览近景 | 局域网地址、Yinqiao API 与四种协议状态 |
| 03 | 1600x1000 | 多账号绑定 | 飞牛音乐账号权限直接复用，凭据本机加密 |
| 04 | 1600x1000 | 系统设置 | 端口可改、协议可独立开关 |
| 05 | 1600x1000 | API 桥分层能力 | 85 条稳定接口，按业务分类说明 |
| 06 | 1600x1000 | OpenSubsonic 支持/不支持表 | 不夸大，每项能力清晰声明 |
| 07 | 1600x1000 | 三方应用支持表 | 平台与协议一眼可见 |
| 08 | 1600x1000 | 关于与安全 | 零修改、权限理由、网络和隐私边界 |
| 09 | 1920x1080 | 架构图 | 客户端 -> 协议 -> Yinqiao API -> 官方服务 |
| 10 | 1024x1024 | 项目图标主视觉 | 青蓝双环 + 紫红蓝玻璃背景 |

架构图必须给官方飞牛音乐画独立边界，并写“依赖官方应用正常运行”“不修改官方文件”。
不要绘制数据库直连箭头；Yinqiao API 到官方服务的箭头标记“本机 HTTP / Unix Socket”。
