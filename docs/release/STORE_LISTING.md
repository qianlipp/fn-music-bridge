## 一句话说明

为飞牛音乐提供多协议第三方音乐 App 接入，独立运行且不改动官方应用。

## 短描述

飞牛音乐暂无官方手机端，音桥在 NAS 本机提供 Yinqiao API、OpenSubsonic、
Audio Station、Jellyfin Audio 和 Ampache 协议，供大量兼容的第三方音乐 App 连接。

## 长描述

音桥是独立安装的第三方 fnOS 应用。它不会包含、替换或修改官方飞牛音乐，
而是把用户已有的账号权限、曲库、歌手、专辑、歌曲、封面、歌词、收藏、歌单与播放流
映射为常见播放器可连接的协议。

应用提供精简的桌面管理窗口，可绑定多个飞牛音乐账号、自定义播放器端口、单独启停
每种协议，并查看 85 条 Yinqiao API 路由和各协议明确的支持/不支持能力。凭据使用
AES-256-GCM 保存在 NAS 本机。协议服务仅以普通应用身份运行，不破解或绕过鉴权，
不修改 fnOS、官方应用、数据库和用户曲库，不读取无关用户文件。除响应用户主动配置的
播放器外，不向开发者服务器或第三方云端发送数据，也不包含广告、遥测或行为分析。

默认端口为可信局域网明文 HTTP，不会自动内网穿透。外网使用需要用户自行部署 HTTPS、
VPN 和访问控制。仅应用于用户合法拥有或获授权的音乐内容。
