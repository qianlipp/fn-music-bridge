## 标题

【第三方应用】音桥 1.0.5：让局域网播放器连接自己的飞牛音乐曲库

## 正文

这是一个独立安装的第三方 fnOS 应用，不是飞牛官方应用，也不是飞牛音乐修改版。
它不会包含、替换或修改官方飞牛音乐的文件、前端、配置和数据库；使用前仍需从应用
中心正常安装并运行官方飞牛音乐。

音桥把用户已有的音乐账号和曲库权限转换为常见播放器可以理解的接口。
当前提供 Yinqiao API、OpenSubsonic/Subsonic、Audio Station、Jellyfin Audio
和 Ampache API 6 的音乐能力子集。可以在兼容客户端中浏览歌手、专辑和歌曲，搜索、
查看封面与歌词、管理收藏和歌单，并支持音频流式播放和拖动进度。

### 适合谁

- 想在局域网内用自己熟悉的音乐客户端播放 NAS 曲库；
- 正在开发桌面或移动音乐客户端，需要相对稳定的 Yinqiao API；
- 希望一个账号权限体系同时服务多种播放协议。

### 使用方式

1. 确认官方飞牛音乐可以正常登录、浏览和播放。
2. 安装本帖附件中的 `yinqiao` FPK。
3. 从飞牛桌面打开“音桥”。
4. 在账号绑定页使用飞牛音乐中创建的独立账号完成绑定。
5. 在播放器中填写 NAS 局域网 IP、管理页显示的端口以及同一账号密码。

### 安全与权限说明

本应用默认开放局域网明文端口 18090 和 14040，自定义播放器端口也属于局域网服务，
请不要直接映射到互联网。确需外网使用时，请自行配置 HTTPS 反向代理、VPN 和访问
控制。

飞牛音乐账号凭据使用 AES-256-GCM 加密保存在本应用私有数据目录，不上传开发者
服务器；应用没有广告、遥测和行为分析。真机确认官方音乐 Socket 允许普通用户连接，
因此音桥以独立的 `yinqiao:yinqiao` 普通账号运行；不会修改官方应用、访问曲库数据库、
扫描共享目录或挂载 Docker Socket。

### 兼容性边界

这是协议适配器，不是完整的 Jellyfin、DSM 或 Ampache 服务器。视频、直播、播客、
远程会话控制、服务端插件、DSM 管理等无对应音乐能力的接口会明确显示“不支持”。
官方飞牛音乐升级并改变接口后，个别功能可能需要适配更新。

仅限播放自己拥有或已合法获授权的音乐，并遵守 fnOS、飞牛音乐和第三方客户端条款。
