# 项目宣传素材与统一口径

## 标准名称

- 中文：音桥
- 英文：Yinqiao
- 包名：`yinqiao`
- 定位：第三方独立音乐协议桥

## 30 字定位

让局域网播放器在不修改官方应用的前提下，连接用户自己的飞牛音乐曲库。

## 核心信息

1. 独立 FPK，官方飞牛音乐零文件修改。
2. 一个 Yinqiao API，同步适配四类常见音乐协议。
3. 复用飞牛音乐账号、角色和曲库权限。
4. 多账号、端口自定义、协议独立开关。
5. 本机加密凭据，无广告、遥测或开发者云端。
6. 每项协议能力明确标记支持和不支持。

## 必须使用的限定语

- “第三方独立应用”
- “兼容音乐能力子集”
- “需要官方飞牛音乐正常运行”
- “默认面向可信局域网”
- “只连接用户合法拥有或获授权的音乐”

## 禁止宣传用语

- 官方、官方合作、官方认证、官方增强版
- 飞牛音乐修改版、破解版、解锁版
- 绕过限制、解除限制、免鉴权、无限权限
- 完整 Jellyfin、完整 DSM、百分百兼容所有客户端
- 绝对安全、永不失效、永久兼容

## 视觉方向

主视觉使用项目自己的青蓝双环图标与紫红蓝玻璃背景。官方飞牛 Logo 不作装饰；第三方
播放器图标只在兼容列表中等尺寸展示，并附“不代表合作或认证”的说明。
