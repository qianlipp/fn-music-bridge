# 常见问题

## 这是飞牛官方应用或飞牛音乐修改版吗？

不是。它是独立 appname、独立进程和独立数据目录的第三方 FPK，不包含或修改官方包。

## 为什么必须安装官方飞牛音乐？

本应用只做协议转换，曲库、账号、权限、元数据和播放能力仍由官方飞牛音乐提供。

## 为什么不需要 root 运行？

真机检查确认官方音乐创建的 `/var/run/trim_music.socket` 权限为 `0666 root:root`，
普通应用账号可以连接。音桥因此使用独立的 `yinqiao:yinqiao` 账号运行，不读取共享
目录、数据库或 Docker Socket，也不会修改官方应用。

## 密码保存在哪里？会上传吗？

密码经 AES-256-GCM 加密后保存在本应用私有数据目录，不会上传开发者服务器，也不会
写入日志。NAS 的 root 管理员仍属于系统信任边界。

## 为什么账号绑定需要先在管理页操作？

部分客户端只发送摘要而不发送原始密码，网关需要本机保存的加密凭据验证摘要。直接
密码登录的协议仍会转发给飞牛音乐验证，不会使用自建用户系统替代官方鉴权。

## 可以直接外网访问吗？

技术上反向代理后可以，但应用不会自动内网穿透，默认端口是明文 HTTP 且管理写接口
面向可信 LAN。建议使用 VPN 或 HTTPS 反向代理并增加独立访问控制，绝不能裸映射端口。

## Jellyfin 客户端为什么有些功能不存在？

这里只实现 Jellyfin 音乐客户端需要的子集，不是完整影视服务器。视频、直播、插件、
SyncPlay、WebSocket 事件和服务器管理明确不支持。

## 连接显示 401 怎么办？

确认使用的是“飞牛音乐账号”，不是 fnOS 系统账号；在无痕窗口验证该账号能登录官方
音乐；检查账号是否绑定、是否被封禁、是否拥有曲库权限；随后删除并重新绑定。

## 找不到 NAS IP 怎么办？

在系统设置的网络信息中查看局域网 IPv4，手动填入协议桥“局域网主机”。不要填写协议、
端口或路径。

## 官方音乐升级后不能用了怎么办？

先确认官方应用自身正常，再记录版本、失败时间和脱敏日志。Yinqiao API 作为兼容层会集中
适配变化，但不承诺与未发布版本永久兼容。

## 卸载会删除音乐吗？

不会。卸载只处理 `/var/apps/yinqiao/var` 下本应用自己的凭据、设置和日志。
