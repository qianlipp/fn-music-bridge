# 版主/商店审核说明

应用：音桥 `yinqiao` 1.0.5

## 独立性

- `source="thirdparty"`，appname 与官方 `trim.music` 完全不同。
- FPK 只包含本项目编译的两个静态 Go 二进制、桌面入口、图标和说明文档。
- 不包含官方二进制、网页资源、配置、签名或安装脚本。
- 安装、升级、停止和卸载均不写入 `/var/apps/trim.music`。

## 调用关系

音桥服务调用本机 Yinqiao API；Yinqiao API 再通过官方音乐进程提供的本机 HTTP/Unix Socket
入口发起请求。应用不直接读取或修改官方数据库，不反编译或注入官方进程，不改变官方
鉴权、用户角色和曲库权限。

[图片占位：四层数据流图，客户端 -> 音桥服务 -> Yinqiao API -> 官方飞牛音乐；在官方包
周围画清晰边界并标注“零文件修改”]

## 权限和网络

当前使用 `run-as=package`，运行账号和组均为 `yinqiao`。真机确认官方
`/var/run/trim_music.socket` 为 `0666 root:root`，普通应用账号可以连接，因此没有申请
root。应用不访问 `docker.sock`、共享目录或数据库。默认监听 18090/14040 局域网明文
端口，安装向导、管理页、隐私与安全文档均醒目披露；没有自动外网穿透。

## 用户数据

绑定凭据用 AES-256-GCM 加密，本机密钥和密文权限 `0600`。无遥测、广告或云端后端。
卸载向导允许明确选择保留或删除本应用凭据、设置和日志。
