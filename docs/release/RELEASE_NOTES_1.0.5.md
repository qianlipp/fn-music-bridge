# 音桥 1.0.5

1.0.5 提升安装包版本以支持从 1.0.4 直接升级，并优化管理页中的协议推荐顺序与
安全说明。服务接口、绑定账号、设置和 Jellyfin 会话数据沿用原有升级流程，不需要
清空应用数据。

## 主要变更

- 协议顺序调整为 OpenSubsonic、Jellyfin Audio、Audio Station、Ampache。
- OpenSubsonic 和 Jellyfin Audio 标记为“优先推荐”。
- “三方应用”更名为“三方应用支持”。
- 应用说明明确服务以普通应用身份运行，数据保存在 NAS 本机。
- 明确不破解、不绕过鉴权、不修改 fnOS、官方应用、数据库和用户曲库。
- 明确除响应用户主动配置的播放器外，不向开发者服务器或第三方云端发送数据。

## 升级提示

可以直接在 fnOS 应用中心上传 `yinqiao-1.0.5.fpk` 覆盖升级 1.0.4。升级过程会保留
已绑定账号、协议开关、自定义端口和已持久化的 Jellyfin 会话。
