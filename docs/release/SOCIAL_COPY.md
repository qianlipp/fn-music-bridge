Audio Station、Jellyfin 和 Ampache 音乐客户端连接自己的飞牛曲库。

## 100 字

想换一个顺手的手机或桌面播放器，又希望继续使用飞牛音乐的账号、曲库、收藏和歌单？
音桥以独立 FPK 提供 Yinqiao API 和四种常见音乐协议。凭据本机加密，
能力支持情况透明展示，不包含或修改官方飞牛音乐。默认只建议在可信局域网使用。

## 300 字

音桥 1.0.5 优先推荐 OpenSubsonic 与 Jellyfin，并补充普通权限、本地数据与零改动安全说明。它是独立安装的第三方
fnOS 应用，不包含、不替换、不修改官方飞牛音乐；曲库、账号、权限和音频仍由官方服务
按用户已有授权提供。

底层 Yinqiao API 整理了 85 条音乐服务能力，上层同时适配 OpenSubsonic、
Synology Audio Station、Jellyfin Audio 与 Ampache API 6。用户可以绑定多个飞牛
音乐账号、自定义播放器端口、单独开关协议，并在管理页查看每项能力是否真正支持。

凭据使用 AES-256-GCM 保存在 NAS 本机，项目不提供广告、遥测、开发者云端或自动
内网穿透。默认端口属于可信局域网明文服务，外网使用需要自行部署 HTTPS/VPN 与访问
控制。请只连接自己合法拥有或获授权的音乐内容。
